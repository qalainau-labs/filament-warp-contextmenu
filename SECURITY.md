# Security Policy

## Supported versions

Security fixes are released for the latest `1.x` version. Please update to the newest release before reporting.

| Version | Supported |
| ------- | --------- |
| 1.x     | Yes       |
| < 1.0   | No        |

## Reporting a vulnerability

Please do not open a public GitHub issue for security problems.

Email **support@warpui.com** with "Security" in the subject, or use the form at [warpui.com/support](https://warpui.com/support?plugin=contextmenu). Include:

- the version of Warp Context Menu, Filament, Livewire and Laravel,
- the steps to reproduce, and
- what an attacker can see or change.

You will get a reply within 3 business days. Confirmed issues are fixed in a patch release, and the fix is listed in `CHANGELOG.md`. Credit is given in the release notes unless you ask otherwise.

The protections the plugin applies (tenant scoping, authorization before serialization, text rendering) are described in the [Security](README.md#security) section of the README.
