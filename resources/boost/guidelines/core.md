# Warp Context Menu

Use the `warp-contextmenu-development` skill for table and page context menus.

```php
use Qalainau\FilamentWarpContextMenu\WarpContextMenuPlugin;
use Qalainau\FilamentWarpContextMenu\ContextMenu;

WarpContextMenuPlugin::make()->pages();
$table->contextMenu();
ContextMenu::separator();
```
